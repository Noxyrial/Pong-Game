# Pong Game

This is a simple pong game made using C++ and raylib.

## Controls

- `UP arrow` — Move the paddle up
- `DOWN arrow` — Move the paddle down
- `ESC` — Quit the game

## Requirements

- A C++ compiler
- raylib

## What I Learned

1. Using raylib
2. Taking Keyboard Input
3. Detecting Collisions
4. Making a Gameloop
5. Coding a basic computer opponent

This was a small project I made to improve my coding skills and get better at c++.
